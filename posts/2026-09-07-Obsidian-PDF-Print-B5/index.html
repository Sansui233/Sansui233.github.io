用 Obsidian 导出笔记为一本书

2026年9月7日
工具教程
阅读评论

之前在 Memo 里说想把笔记印出来，以方便无法带手机时看。在 Obsidian 里自己有非常仔细调整过排版自己印了，之后还是送去网上的印刷店打印，可以效果差距非常大。专业的还是太专业了，特此记录。

此次 PDF 成品可以 在此下载。

一、Obsidian 导出配置

插件

  • Better Export PDF：可预览，可加目录书签
  • Code Block Customizer：伟大无需多言！代码块终于像样了，完全换掉了 Obsidian live mode 对于代码块的处理方式。
  • Auto Heading：标题自动编号。对于打印来说自动编号是很重要的。不过没有中文数字。
  • 一个文本编辑器，编辑打印用的 CSS 配置

CSS 配置

CSS 现在对于打印 (@media print) 的配置比我想得要多得多……

  • 自动页码，奇偶页码
  • 页眉页脚
  • 按大章节分页
  • 首页占一整页做封面
  • 防止标题被挤到页尾
  • 防止图片跨页

表格的跨页表头还是自动续表的，CSS 还有计数器功能。我惊呆了好吧，原来这么强的吗？已经是符合本次基本的书籍导出的要求了。新的 CSS 还在加印刷相关的内容。

Typst 更强也好用，但就一般笔记导出成书而言还是 markdown + css 快且广泛。

上面具体配置我就不细说了，因为本人酷爱装修，样式都是长期累积的结果，印刷用的主题也是在原主题的基础上又叠了一层修修补补，直接放到 gist 链接上了。

软件

一定要一个可以读取屏幕 dpi 查看实际大小的软件。Photoshop 是可以的， SummatraPDF 经过设置后也是可以的。其他的我没有试过。

以 SummatraPDF 为例，在「设置」→「高级选项」中，设置 CustomScreenDPI = 189 。其中 189 是我的屏幕 DPI 。你可以直接查阅屏幕型号，或到 这里 计算。

然后重启 SummatraPDF， Ctrl+1 就是打印大小了。

二、排版

对于主题，初期我尝试了使用网页风格无衬线主题 ，效果算是非常非常不行，主要打印出来的字非常大一个，而且粗细对比过强，网页感太重了。

对于一般的纸张，书籍印刷确实非常不适合使用粗体字（Bold, weight 600)，除非你用铜版纸这类不吸墨的纸。500 的字重比较适合。

适合印刷的主题是需要重新写的，才有了上面的效果。

纸张

可以说 纸张 和 纸张大小 在印刷里的重要程度能占 60%。

  • 纸张种类：道林纸（双胶纸），本白色。
  • 纸张大小：B5。

首先是排除办公复印用的荧光剂 A4 纸。这个纸，即便你裁为 B5 的大小，认真胶装，加上铜版纸封面。但那种挺度、表面质感和刺眼的荧光白，仿佛小学复印店里复印出来的一样（实际上就是）。

道林纸（双胶纸）是一种比较常见的纸张。值得注意的是，除非你住印厂旁边，街边的复印店是不会准备本白色的双胶纸的，连大学毕业论文打印的地方都是荧光白A4纸。我走完了一条街的广告店，有个女店主很认真介绍了她存放的纸的种类，说对于特种纸要提前给工厂定制，存放也是有要求的。

如果不想寄印，只能自己买一打回去，带给打印店了。

至于为什么 B5 大小……真的会觉得 A4 纸像书吗？

字号

配置
  • 网页： 16px
  • Obsidian Better Export 导出缩放：80%
  • 实际大小：9.6pt

Chromium 的 PDF 导出以 96dpi 导出，于是 16px 的字体对应的是 12pt。之前买过 Rei 的《印刷排雷手册》，12pt 在正文印刷里已经算是老年人字号了。

因为我想制作册子，使用的是 B5 大小印刷。在初期，我只是问了 AI 缩放到 85% 是否可行（字体大小10.2pt），AI 说可以，我印出来也觉得凑合。但当我拿到专业印厂的印刷后，才发现 10.2 pt 和 9.6 pt 虽然看起来差不太多，但舒适度差距比想象得大…… 10 pt 还是更适合 A4 尺寸。

边距

配置
  • css:
css
@media print {
    @page {
        margin: 12mm 10mm 14mm; /* 正文 80% 缩放不知自带 6mm 边距*/
    }
}
  • 实际边距：左 16mm，上 18mm，右 16mm，下 20mm

我没有搞懂为什么 margin 为 0 还是有自带了边距，有可能是我的原来的傻逼主题干的（并不）。

实际边距是 GPT 的推荐值，也是我从印厂拿到的胶印书籍里的测量值。

行间距与段间距

这部分反而是祖宗之法。

  • 行间距: 1.5倍。
  • 段间距: 1倍 margin。

1.5 倍行间距也是考虑到我的笔记有大量的 bullet，没有超过 3 行的长段落，大概比较像教材。小说类的行间距是更稀疏的。

装订

我对册子要求就是能平摊，能平摊，能平摊。我讨厌不工整的纸，谢谢。

最开始我使用了固体胶装，牢固是牢固的，但是好像，因为真的干不了所以到处黏纸……后面还是使用了经典的白乳胶放一晚上，非常牢固且照顾手残。

而印厂因为能打印 B3 的尺寸，小册直接用骑马钉了。

印厂的调整

我发给印厂的 PDF 存在着诸多问题。不标准的字体大小，下边距过窄。但是印厂把各个边距给我裁得相当之标准。骑马钉所在的内侧边距要微大于右侧边距。

我的上边距是标准的，所以印厂没有变上边距，只是整体缩小给了下边距和左右边距正确的选择，，可以说是非常细致地排版过了。

最难的灰度网点，AM 胶印的细腻的网点，家用的激光打印机打不出来……真的打不出来。

整个印刷质量、均匀程度和办公用的激光打印机相比，实在差得太多了。
